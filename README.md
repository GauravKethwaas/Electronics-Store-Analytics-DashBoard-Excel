# Interactive Sales Analytics Dashboard (Excel)

📌 Overview
This project is a fully interactive Electronics Store Analytics Dashboard built in Excel (2024 version, compatible with Excel 2019 and later).  
It provides a comprehensive view of product sales, salesman performance, regional distribution, and monthly trends.

🔑 Key Features
- Sales by Product: Highlights top 3 selling products (Printer, Mouse, Monitor) and least selling ones.  
- Sales by Salesman: Compares performance across team members with clear top/poor performer charts.  
- Sales by Region: Breaks down sales across East, North, South, and West regions.  
- Sales by Month: Line chart showing monthly sales trends for 2021.  
- Key Metrics: Total Sales – 366 | Total Amount – 1,782,570.  

🎨 Design
- Blue-themed professional UI  
- Sidebar navigation (Dashboard, Products, Salesmans, About)  
- Interactive filters for Date, Region, and Product  

📈 Impact
This dashboard is not just a visualization tool – it demonstrates how **data-driven insights** can guide better business decisions.  
From identifying top-performing salesmen to spotting weak regions and products, the dashboard highlights the **power of analytics in Excel**.
